## ▶️ Run Locally

Because this portfolio is a self-contained HTML website, no Node.js installation or build process is required.

1. Clone the repository:

```bash
git clone https://github.com/Abhi8579/portfolio.git
```

2. Open the project folder.
3. Open `index.html` in a browser.

For a local development server, you can also use VS Code's **Live Server** extension.

## 🚀 Deploy with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save the settings.
7. GitHub will generate the public portfolio URL.
